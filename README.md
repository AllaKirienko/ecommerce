# E-commerce

В рамках домашнего задания реализованы классы `Product` и `Category`.

Класс `Product` описывает товар и содержит название, описание, цену и количество товара в наличии.

Класс `Category` описывает категорию товаров и содержит название, описание и список продуктов.

Также реализован автоматический подсчет общего количества категорий и товаров с помощью атрибутов класса `Category`.

Для проверки функциональности написаны тесты с использованием `pytest`.
Покрытие функционального кода тестами составляет 100%.
## Наследование классов продуктов

Добавлены классы-наследники класса `Product`:

- `Smartphone` — класс для смартфонов с дополнительными атрибутами:
  - производительность (`efficiency`);
  - модель (`model`);
  - объем встроенной памяти (`memory`);
  - цвет (`color`).

- `LawnGrass` — класс для газонной травы с дополнительными атрибутами:
  - страна-производитель (`country`);
  - срок прорастания (`germination_period`);
  - цвет (`color`).

Также реализована проверка совместимости товаров при сложении: складывать можно только товары одного класса.

Метод добавления товаров в категорию дополнен проверкой типов, чтобы добавлять можно было только объекты класса `Product` и его наследников.

Для проверки функциональности написаны тесты с использованием `pytest`.

## Абстрактные классы и миксины

Добавлен абстрактный базовый класс `BaseProduct`, который содержит общую функциональность для продуктов.

Класс `Product` наследуется от `BaseProduct` и реализует обязательный метод отображения информации о продукте.

Также реализован класс-миксин `PrintMixin`, который выводит информацию о создании объектов продуктов с указанием класса и переданных параметров.

Для проверки новой функциональности добавлены тесты с использованием `pytest`.

Покрытие функционального кода тестами составляет более 75%.

## Обработка исключений и средняя цена

Добавлена проверка количества товара при создании объекта `Product`. Если количество равно нулю, вызывается `ValueError` с сообщением:
`Товар с нулевым количеством не может быть добавлен`.

В класс `Category` добавлен метод `average_price()`, который рассчитывает среднюю цену товаров категории. Для пустой категории метод возвращает `0`.

Для новой функциональности добавлены тесты с использованием `pytest`.
Покрытие функционального кода тестами составляет 99%.
